# 🐾 Gemini 猫娘安卓手机悬浮桌宠（灵动胶囊 + 一键截屏识图 + 语音播报）

原生 **Kotlin + Android** 轻量工程，已内置 **14 套透明 `.webp` 差分表情**，并自带 **GitHub Actions 云端自动打包 `.apk`** 工作流（无需安装 Android Studio）。

## ✨ 核心特色

* **💊 顶部灵动胶囊模式（默认）**：隐藏在手机最上方挖孔/状态栏区域，平时仅占极窄迷你胶囊；点击或触发吐槽时平滑展开显示表情与文字，说完自动收回，几乎零遮挡。
* **🫧 三种形态长按一键切换**：长按悬浮窗即可在 **顶部灵动胶囊** ↔ **半透明悬浮小人** ↔ **贴边隐身小把手** 之间自由切换，并支持滑块调节气泡透明度。
* **📸 一键唤醒截屏吐槽**：点击顶部胶囊 / 下拉控制中心「召唤猫娘截屏」快捷磁贴 / 通知栏快捷按钮，立刻内存级截屏（阅后即焚、0 硬盘占用）发给 `gemini-3.5-flash-lite` 吐槽当前画面。
* **🔊 语音播报（TTS）**：不想看文字时开启语音播报，自动调用安卓系统中文语音引擎朗读她的每一句吐槽（自动过滤颜文字、微调甜美音调）。
* **🎭 完整养成体系**：保留全部 14 套表情、90 秒挂机打盹、6×6 性格行为组合、随机心情、`-100 ~ +100` 双向好感度与小鱼干/主人的酸奶投喂。

## 📦 3 分钟免费获取 `.apk` 安装包（免装 Android Studio）

1. 在 GitHub 新建一个仓库（**私有仓库 Private 也可以**）。
2. 把解压后的整个 `gemini-pet-android` 文件夹里的所有文件（**务必包含隐藏目录 `.github/workflows/build-apk.yml`**）上传推送到仓库的 `main` 分支。
3. 打开仓库顶部的 **Actions** 页面，等待约 2–3 分钟构建变绿 ✅。
4. 点进该次构建页面，在底部 **Artifacts** 下载 **`gemini-pet-android-apk`**，解压出 `app-debug.apk` 发到安卓手机安装即可！

## 📱 手机端首次使用

1. 打开 App，先填好你的 Google AI Studio API Key（推荐模型 `gemini-3.5-flash-lite`）并点 **保存配置**。
2. 点 **授权悬浮窗** → 开启「在其他应用上层显示」。
3. 点 **🚀 启动并授权截屏** → 确认一次录屏/截屏授权，顶部灵动胶囊立即生效！
4. 推荐下拉手机控制中心 → 编辑快捷开关 → 把 **「召唤猫娘截屏」** 磁贴拖到常用位置，刷任何 App 随时一键召唤。
